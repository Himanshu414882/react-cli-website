Features

Everything you need to build React apps

From project scaffolding to production builds, React CLI has you covered.

Project Scaffolding

Create fully configured React + TypeScript + Vite projects in seconds with sensible defaults.

Code Generation

Generate components, pages, hooks, services, contexts, layouts, and type definitions with a single command.

Dev Server

Start a lightning-fast Vite development server with hot module replacement out of the box.

Testing & Linting

Run tests with Vitest and lint code with ESLint — fully integrated into the CLI workflow.

Configurable

Customize generators, directories, and commands through a simple rcli.json config file.

Web-Based GUI

Launch a visual project creator with mycli gui — a graphical interface for interactive project setup.

Install in seconds

Get started with a single command.

npm install -g mycli

Quick Start

Up and running in minutes

Follow these steps to create your first React app with React CLI.

1

Install the CLI

Install React CLI globally using npm.

Terminal 
$ npm install -g mycli
2

Create a new project

Scaffold a new React + TypeScript + Vite project with a single command.

Terminal 
$ mycli new my-app
$ cd my-app
3

Generate code

Use the generators to quickly create components, pages, hooks, and more.

Terminal 
$ mycli generate component UserCard
$ mycli generate page Dashboard
$ mycli generate hook useAuth
$ mycli generate service user
4

Start developing

Launch the dev server, run tests, lint, and build — all from the CLI.

Terminal 
$ mycli serve    # Start dev server
$ mycli test     # Run tests
$ mycli lint     # Lint code
$ mycli build    # Production build
Configuration

Customize to your workflow

Every project includes an rcli.json file for full control over generators, directories, and build targets.

rcli.json
{
  "$schema": "https://rcli.dev/schema.json",
  "project": {
    "name": "my-app",
    "type": "react"
  },
  "generators": {
    "component": {
      "directory": "src/components",
      "test": true,
      "index": true
    },
    "page": {
      "directory": "src/pages"
    }
  },
  "targets": {
    "serve": { "command": "vite" },
    "build": { "command": "vite build" },
    "test": { "command": "vitest" },
    "lint": { "command": "eslint ." },
    "format": { "command": "prettier --write ." }
  }
}
📁

Custom Directories

Define where each generator places files — src/components, src/pages, or any path you prefer.

🧪

Test Generation

Control whether test files are auto-generated alongside your components, hooks, and services.

📦

Barrel Exports

Automatically update index.ts barrel files when generating new modules.

🎯

Build Targets

Map CLI commands to any underlying tool — Vite, Vitest, ESLint, Prettier, or your own scripts.
